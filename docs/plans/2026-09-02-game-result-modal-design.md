# 게임 결과 모달 설계

## 목표

서버가 대국 종료 상태를 전달하면 각 플레이어에게 자신의 관점에 맞는 승리 또는 패배 결과를 즉시 보여준다.

## 동작

- `state_changed` 메시지의 상태가 처음 `finished`가 되는 순간 결과 모달을 한 번 연다.
- `gameState.winner`와 내 돌 색(`me.color`)이 같으면 `승리했습니다!`, 다르면 `패배했습니다`를 표시한다.
- 시간 초과 종료라면 보조 문구로 승자는 `상대방의 시간이 초과되었습니다.`, 패자는 `제한 시간 30초가 초과되었습니다.`를 표시한다.
- 일반 오목 종료라면 승자는 `오목을 완성했습니다.`, 패자는 `상대방이 오목을 완성했습니다.`를 표시한다.
- 확인 버튼을 누르면 페이지를 새로 불러 로비로 돌아간다.
- 배경 클릭과 Esc 키로는 닫히지 않는다. 결과를 확인하기 전 실수로 모달이 사라지는 것을 막는다.

## 화면과 접근성

- 기존 게임의 목재 보드 및 주황색 강조색과 어울리는 전용 모달을 사용한다.
- 결과 아이콘, 제목, 사유, `로비로 돌아가기` 버튼으로 구성한다.
- 모달은 `role="dialog"`, `aria-modal="true"`, 제목·설명 연결 속성을 가지며 열릴 때 버튼으로 포커스를 이동한다.
- 승리와 패배는 문구와 아이콘을 함께 사용해 색상에만 의존하지 않는다.
- 작은 화면에서도 보드 위 중앙에 맞고, 모션 감소 설정에서는 등장 애니메이션을 제거한다.

## 테스트

- HTML에 접근 가능한 결과 모달과 로비 버튼이 존재하는지 확인한다.
- 클라이언트 결과 계산을 순수 함수로 분리해 일반 승리·패배와 시간승·시간패를 검증한다.
- 같은 종료 상태가 반복 수신되어도 모달 표시가 한 번만 실행되는 구조를 확인한다.
- 전체 테스트, 정적 빌드, Wrangler dry-run을 실행한다.
