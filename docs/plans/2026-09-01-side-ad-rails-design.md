# 좌우 광고 레일 설계

## 목표

온라인 오목 게임의 중앙 레이아웃을 유지하면서 데스크톱 화면 양쪽에 카카오 애드핏용 160×600 광고 슬롯을 하나씩 제공한다.

## 레이아웃

- 페이지 최상위에 좌측 광고, 중앙 앱, 우측 광고로 구성된 3열 셸을 둔다.
- 좌우 광고 슬롯은 각각 160×600 크기를 유지한다.
- 중앙 앱은 기존 최대 너비와 반응형 동작을 유지한다.
- 광고와 중앙 앱 사이에는 일정한 간격을 둔다.
- 화면 폭이 약 1,300px 미만이면 광고 슬롯을 숨겨 게임판 크기와 사용성을 보호한다.

## 광고 연결

- 현재는 각 슬롯에 `AD 160 × 600` 자리 표시만 렌더링한다.
- 나중에 카카오 애드핏에서 발급한 스크립트와 광고 단위 요소를 각 슬롯 내부에 교체할 수 있게 독립 컨테이너를 사용한다.
- 광고가 로드되지 않더라도 중앙 앱의 위치나 크기는 변하지 않는다.

## 테스트

- HTML에 좌우 광고 슬롯이 각각 존재하는지 검사한다.
- 각 슬롯에 카카오 광고 코드를 삽입할 수 있는 독립 컨테이너가 있는지 검사한다.
- CSS에 160×600 크기와 좁은 화면 숨김 규칙이 있는지 검사한다.
