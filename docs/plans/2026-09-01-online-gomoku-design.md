# 온라인 1:1 오목 설계

## 목표

플레이어가 닉네임만 입력해 방을 만들고, 6자리 참여 코드를 공유하여 인터넷에서 실시간 1:1 오목을 플레이할 수 있게 한다. 자유룰과 렌주룰을 지원하며 게임 상태와 규칙 판정은 서버가 관리한다.

## 기술 구조

- 기존 HTML, CSS, JavaScript 클라이언트를 유지한다.
- Node.js WebSocket 서버를 추가한다.
- 서버가 방, 사용자 연결, 턴, 보드, 금수, 승패의 최종 상태를 관리한다.
- 클라이언트는 사용자 입력을 서버로 보내고 서버가 확정한 상태만 화면에 반영한다.
- 방 데이터와 닉네임은 메모리에만 보관하며 영구 저장하지 않는다.

## 방 생성과 참여

1. 방장은 닉네임과 룰을 선택하고 방을 만든다.
2. 서버는 영문 대문자와 숫자로 구성된 6자리 참여 코드를 발급한다.
3. 방장은 참여 코드를 복사해 상대에게 공유한다.
4. 참가자는 닉네임과 참여 코드를 입력해 방에 들어간다.
5. 방장은 흑, 참가자는 백으로 첫 대국을 시작한다.
6. 두 명이 모이기 전에는 보드를 잠그고 상대를 기다린다.
7. 세 번째 사용자의 입장은 거부한다.

## 게임 진행

서버는 착수 요청마다 다음 항목을 순서대로 확인한다.

1. 방과 대국이 유효한지 확인한다.
2. 요청한 사용자의 차례인지 확인한다.
3. 해당 교차점이 비어 있는지 확인한다.
4. 렌주룰의 흑이라면 금수인지 확인한다.
5. 유효한 수만 보드에 반영해 양쪽 클라이언트에 전송한다.
6. 승리 또는 무승부를 판정한다.

클라이언트는 현재 룰, 양쪽 닉네임과 돌 색상, 현재 턴, 참여 코드 복사 버튼을 표시한다. 마지막 착수에는 별도 테두리를 표시한다.

## 룰

### 자유룰

- 흑과 백 모두 가로, 세로, 대각선으로 돌이 5개 이상 연결되면 승리한다.

### 렌주룰

- 흑은 정확히 5개를 연결하면 승리한다.
- 흑의 삼삼, 사사, 6개 이상 장목 착수는 금지한다.
- 백은 5개 이상 연결하면 승리한다.
- 흑 차례에는 금수 위치를 반투명한 빨간 X로 표시하고 클릭을 막는다.
- 금수 표시에 마우스를 올리거나 터치하면 삼삼, 사사, 장목 중 해당 이유를 보여준다.

## 종료와 재대국

- 어느 한쪽의 WebSocket 연결이 끊기면 대국과 방을 즉시 종료한다.
- 연결 종료는 승리 전적에 포함하지 않는다.
- 남은 사용자에게 상대의 연결이 끊겨 대국이 종료되었다는 메시지를 표시한다.
- 정상 종료 후에는 재대국 또는 나가기를 선택할 수 있다.
- 재대국은 두 플레이어가 모두 동의해야 시작한다.
- 재대국마다 흑과 백을 교체한다.

## 오류 처리

- 존재하지 않는 코드에는 방을 찾을 수 없다는 메시지를 표시한다.
- 정원이 찬 방의 추가 입장을 거부한다.
- 참여 코드는 입력 단계에서 6자리 형식으로 정규화하고 검증한다.
- 잘못된 턴, 중복 위치, 금수 착수는 서버가 거부하고 보드를 변경하지 않는다.
- 방장이 대기 중 연결을 끊으면 빈 방을 즉시 삭제한다.

## 테스트

- 자유룰의 가로, 세로, 양 대각선 승리와 장목 승리를 검증한다.
- 렌주룰의 정확한 5목 승리와 삼삼, 사사, 장목 금수를 검증한다.
- 잘못된 턴, 중복 위치, 종료 후 착수가 거부되는지 검증한다.
- 방 생성, 코드 입장, 정원 제한, 연결 종료 시 정리를 검증한다.
- 재대국 동의와 흑백 교체를 검증한다.
- 실제 브라우저 두 창에서 방 생성부터 대국 종료까지 통신 흐름을 확인한다.
